# Build a macOS DMG

Builds an unsigned release DMG on this Mac. This is not a release: nothing is tagged or pushed (that's `/ship release`, which has `release.yml` build every platform).

## Project location

The Larp repo lives at `~/Downloads/sush-pack/larp` (`$HOME/Downloads/sush-pack/larp`), next to its sibling projects in `~/Downloads/sush-pack/`. Every command and path below is relative to that folder; `cd` there first, whatever the current directory is.

## 1. Preconditions

- Running on macOS (`uname`). If not, stop and say so.
- The project folder exists (`test -d "$HOME/Downloads/sush-pack/larp"`). If not, stop and say so.
- Mention uncommitted changes (`git -C "$HOME/Downloads/sush-pack/larp" status --short`) if there are any. They are included in the build.

## 2. Build

Run from `~/Downloads/sush-pack/larp`, in the background (the first release build compiles whisper.cpp with Metal and takes several minutes). Capture the real exit code; don't pipe the build into `tail`, which hides it.

```sh
cd "$HOME/Downloads/sush-pack/larp"
bun install
bun run build:mac > "$TMPDIR/larp-build.log" 2>&1
echo "EXIT $?"
tail -10 "$TMPDIR/larp-build.log"
```

`build:mac` (root `package.json`) does the following:

- Puts `~/.cargo/bin` on PATH, since Rust may not be on the shell's PATH.
- `MACOSX_DEPLOYMENT_TARGET=11.0`, matching `bundle.macOS.minimumSystemVersion` in `tauri.conf.json`: whisper.cpp uses `std::filesystem` (macOS 10.15+), and Tauri's default target is 10.13, so the build can fail without it.
- `--bundles dmg` builds only the DMG (Tauri's `beforeBuildCommand` runs the tsc + Vite frontend build first).

Unlike Sush there's no sidecar or separate release config: `tauri.conf.json` is the whole bundle config, including `Entitlements.plist` (audio input) and `Info.plist` (the microphone usage string).

`tauri.macos-icon.conf.json` (the macOS 26 adaptive icon) is left out because it needs full Xcode's `actool`. If `xcrun --find actool` succeeds, run `apps/desktop/src-tauri/icons/build-mac-icon.sh` first and append `-- --config src-tauri/tauri.macos-icon.conf.json` (or run the steps by hand). That overlay bundles `icons/Assets.car` and swaps in `Info.icon.plist`, which adds `CFBundleIconName` and repeats the microphone string from `Info.plist`; if you change one plist, change both. If `actool` is missing, say so in the report: the DMG falls back to the static light `icon.icns` everywhere (the running Dock icon still follows the theme via `dock.rs`).

`AppIcon.icon/Assets/{light,dark}.png` are generated by `icons/source/make_icons.py`; don't edit them by hand.

## 3. If it fails

Quote the first real error from the log (`grep -n "error" "$TMPDIR/larp-build.log" | head`).

- `'path' is unavailable: introduced in macOS 10.15` even with the env var set: a stale whisper CMake cache from a build without it. Run `cargo clean --release -p whisper-rs-sys` and build again.
- `cmake` or libclang missing: an environment problem (`brew install cmake`; libclang comes with the Xcode Command Line Tools), not a code failure.
- A `tsc` error: the frontend doesn't typecheck. Report it like `/typecheck` would; it isn't a packaging problem.

## 4. Report

Give the full DMG path (`~/Downloads/sush-pack/larp/target/release/bundle/dmg/Larp_<version>_<arch>.dmg`) and size, and note:

- It runs only on this Mac's architecture (aarch64 = Apple Silicon only).
- It is unsigned. On another Mac, open it with right-click → Open, or run `xattr -cr /Applications/Larp.app` after copying it in.
- It requires macOS 11 or later.
- After installing, macOS asks for Microphone access on first dictation, and pasting needs Larp enabled under System Settings → Privacy & Security → Accessibility. An unsigned rebuild counts as a new app, so a previously granted Accessibility entry may need removing and re-adding.
